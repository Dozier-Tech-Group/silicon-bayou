# Builder letters

Weekly letters from the people building merged: what shipped, what broke, what the agent fleets are doing, and what is not done — every claim linked to a repo file, an onchain record, or the live site.
Cadence is weekly; a letter is published by committing its markdown file to this directory and adding it to `index.json` (newest first), which the site renders as the letters page.
Letters are never edited after publication. Corrections ship as a dated correction note in the next letter — and the git history of this directory is public, so any edit would be visible anyway.
