# The board goes live, and Merged Public moves out

*Letter 002 · 2026-08-25 · the merged build crew*

## What shipped this week

**The Fleet Operations Board is live**, at [mergedpublic.com/fleet](https://www.mergedpublic.com/fleet/). It has no backend: the three files in [fleet-board/](https://github.com/Dozier-Tech-Group/silicon-bayou/tree/master/fleet-board) run entirely in the visitor's browser, reading Robinhood Chain by hand-built `eth_call`, Blockscout's REST API for indexed history, and GitHub's public API for CI runs — the same sources anyone else can query. Four panels: supply, the BountyBoard work queue decoded straight from its raw event log, Gator Works CI pipeline runs, and the Merged Credit ledger. The board reports; it holds no keys and cannot move anything. Not endorsed by Robinhood.

Before it shipped, an adversarial review filed 21 findings against it, all closed the same day: the empty-state copy could have shown a false "queue clear" when a data source was actually unreachable, old bounties could have fallen off the list without Blockscout-style pagination, and embed mode was hiding the compliance line instead of showing it ([hardening commit](https://github.com/Dozier-Tech-Group/silicon-bayou/commit/acb756f2ce3fa9501ad8acd74ea3c00fa607e289)).

**Merged Public's Phase A closed out.** Gate A passed 2026-08-19: the assignment engine produced byte-identical output across three fresh runs, independently reproduced by a separate verifier. The public verifier that ships with it, [`verify-mp.mjs`](https://github.com/Dozier-Tech-Group/silicon-bayou/blob/master/generator/merged-public/verify-mp.mjs), caught all 8 of 8 deliberately corrupted test sets in mutation testing. Record: [MP-REVEAL.md](https://github.com/Dozier-Tech-Group/silicon-bayou/blob/master/MP-REVEAL.md). The engine itself stays private until reveal, by design — publishing it early would let anyone precompute the draw.

**The Season Zero manifest is published.** The commitment for the Archive Game's Legendary Hunt is on record in [game/season-zero/](https://github.com/Dozier-Tech-Group/silicon-bayou/blob/master/game/season-zero/README.md), hashed and ready. It only counts once that hash is echoed in a zero-value transaction from the treasury on chain 4663 — that echo has not been sent, so no clues are live yet.

**Merged Public moved to its own repository.** As of 2026-08-20, MP is a separate project, [Dozier-Tech-Group/merged-public-archive](https://github.com/Dozier-Tech-Group/silicon-bayou/blob/master/README.md), with its own contracts, docs, and work board. The collection is unchanged on chain — only its home and its rails moved. Here, that prep work landed as a new `MergedPublicBoard` contract (identity-gated instead of gator-gated, 8 tests) and a wind-down script for the old BAYOU-gated BountyBoard ([scripts/winddown-bountyboard.js](https://github.com/Dozier-Tech-Group/silicon-bayou/blob/master/scripts/winddown-bountyboard.js)) — written but not yet run.

**Dependabot kept the lights on.** Three dependency PRs merged on their own: OpenZeppelin contracts to 5.6.1 ([#4](https://github.com/Dozier-Tech-Group/silicon-bayou/pull/4)), and `actions/checkout` and `actions/setup-node` to major version 7 ([#3](https://github.com/Dozier-Tech-Group/silicon-bayou/pull/3), [#2](https://github.com/Dozier-Tech-Group/silicon-bayou/pull/2)).

## What broke, and how it was caught

The Fleet Board's `/fleet` URL 404'd on its own stylesheet and script. The hosting platform serves a physical directory at both `/fleet` and `/fleet/`, and its route-redirect rule loses to that physical content — verified live, `/bayou` redirected with a 301 and `/fleet` did not. At the slashless path, the page's relative `board.css`/`board.js` references resolved against the domain root instead of the fleet directory and failed to load. The fix was an in-page guard that redirects before any asset reference is evaluated ([commit](https://github.com/Dozier-Tech-Group/silicon-bayou/commit/1c4ac7e99106d8ba7bcce1b92f3ae064d390b8f6)). Its own test then turned out to be checking the guard's comment text instead of the actual stylesheet link — caught and fixed the same day ([commit](https://github.com/Dozier-Tech-Group/silicon-bayou/commit/59d6722784805b55c51a207f1e122a6a829b24fe)).

## How to push on us

Open a feature request on the [issue tracker](https://github.com/Dozier-Tech-Group/silicon-bayou/issues) with the `feature-request` label, and thumbs-up the ones you want — votes are how we order the queue. Nobody has filed one yet; the form is live and waiting. Funded bounties ([agents/tasks.json](https://github.com/Dozier-Tech-Group/silicon-bayou/blob/master/agents/tasks.json)) are how demand becomes supply: when something is wanted and specified, it gets a bounty, and an agent or a person works it.

The standing commitments do not move: no yield, no APY, no price talk, ever. These tokens are cryptographic identity, not legal contracts or securities; game rewards are recognition and access only. Holders and Louisiana come first. Built on Robinhood Chain. Not endorsed by Robinhood.
